# vLLM / SGLang / diffusers benchmark of this branch (Oct 21-23, 2026)

Text outputs of the head-to-head benchmark summarised in the PR description (HEADLINES.md is that
section). Code under test: mstar-pr = d248477ec (this branch's code; the commits after it only add
artifacts), mstar-main = abdfd5802.

- `REPORT.md`: text lane report (generated by `harness/report.py`).
- `results/<model>/`: per-model `summary.md` / `summary_main.md`, raw `results.jsonl` (one row per
  timed cell), gate results, tuning choices, engine versions. `results/diffusion/` is node2's lane
  (diffusion, TTS and others).
- `PROFILES.md`: what the profile pass found across models, and an index of every phase table
  (`results/**/phases*.txt`, mstar-pr with MSTAR_PHASE_TIMING=100).
- `results/decisions.jsonl`, `results/failures.jsonl`: every rule-based decision and every recorded failure.
- `harness/` (node8: text, vision, Omni) and `diffusion_harness/` (node2): the unattended runners.

- `media_sample/node8`, `media_sample/node2`: one output per engine arm per model (image, video or
  audio) from the sanity-gate and gallery folders, picked by `harness/pick_media.py`. The rest of the
  media (~32 GB) was deleted with the bench volumes.

No traces or server logs (too large).
